6. LOCKED 대상은 새 변경 요청, 버전, QA와 승인 없이 수정하지 않는다.
7. 각 범위에는 하나의 활성 기준본을 등록하고 사전 릴리스가 정식본을 자동 대체하지 않게 한다.
8. 필요한 마이그레이션, 지원 버전, 폐기 기한과 통제된 롤백 절차를 제공한다.
9. 공개·승인된 버전 번호를 재사용하지 않고 과거 파일과 승인 증거를 보존한다.
10. 변경 이력, 승인 기록, 기준본 등록부와 실제 파일·상태를 항상 일치시킨다.
