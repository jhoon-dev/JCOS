## 문서 범위

COR-004는 JCOS를 상속하는 모든 프로젝트의 공통 출처 정책을 정의한다. 주장별 증거 요구, 출처 우선순위, 권위와 1차 자료, 현재성·버전·관할, 독립성·이해관계, 교차 검증과 충돌, 인용·링크·보존, 인수인계와 정정을 다룬다.

17개 장, `SRC-001`부터 `SRC-050`까지 50개 규칙, 표준 출처 처리 수명주기, 준수 체크리스트와 AI용 압축 지침을 포함한다. 검색 도구별 실행 순서와 세부 팩트체크 절차는 후속 Workflow 범위로 유지한다.
