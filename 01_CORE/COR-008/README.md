## 문서 범위

COR-008은 JCOS를 적용하는 과정에서 발생하는 충돌·예외·불확실성을 일관되게 처리하는 공통 의사결정 규칙을 정의한다. 충돌 탐지와 분류, 우선순위 적용, 사용자 의도와 범위, 근거와 불확실성, 선택지와 트레이드오프, 예외, 에스컬레이션과 중단, 가역성·위험·시간, 결정 기록과 검토를 다룬다.

17개 장, `DEC-001`부터 `DEC-050`까지 50개 규칙, 표준 의사결정 수명주기, 준수 체크리스트와 AI용 압축 지침을 포함한다. 개별 Project Module의 도메인별 판단 규칙은 각 Project 문서 범위로 유지한다.

## 상태 전환
