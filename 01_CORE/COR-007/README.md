## 문서 범위

COR-007은 JCOS를 상속하는 모든 관리 대상의 공통 버전·승인 정책을 정의한다. 버전 식별, Major·Minor·Patch 변경 분류, DRAFT부터 ARCHIVED까지 상태 수명주기, 변경 요청·영향 분석, 검토·승인, LOCKED 통제, 기준본, 마이그레이션, 폐기·롤백과 감사 기록을 다룬다.

17개 장, `VER-001`부터 `VER-050`까지 50개 규칙, 표준 버전 수명주기, 준수 체크리스트와 AI용 압축 지침을 포함한다. 개별 충돌·예외·불확실성 판단은 `COR-008` 범위로 유지한다.
