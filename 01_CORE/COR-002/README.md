## 문서 범위

COR-002는 JCOS를 상속하는 모든 프로젝트의 공통 글쓰기와 편집 원칙을 정의한다. 독자와 목적, 메시지 구조, 섹션·문단·문장, 명확성과 정확성, 어조와 용어, 제목·요약·결론, 편집과 확정 원고 품질 게이트를 다룬다.

17개 장, `WRT-001`부터 `WRT-050`까지 50개 규칙, 표준 작성 수명주기, 준수 체크리스트와 AI용 압축 지침을 포함한다. 조사 범위와 출처 검증은 후속 `COR-003`, `COR-004`에서 다룬다.

## 상태 전환

현재 상태는 `LOCKED`다. 범용성·내용·형식 QA와 사용자 명시적 승인을 통과한 JCOS v2.0.0 기준본이며, 변경은 COR-007에 따른 새 버전·QA·승인 절차로만 수행한다.
