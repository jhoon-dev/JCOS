## 문서 범위

COR-006은 JCOS를 상속하는 모든 프로젝트의 공통 파일 생성·패키징·전달 정책을 정의한다. 전달 요구사항, 형식과 변형, 파일명·경로, 생성·보존·무결성, 패키지·의존성, 보안·권한, 호환성·접근성, 다운로드·수신, 실패·복구와 전달 기록을 다룬다.

17개 장, `FILE-001`부터 `FILE-050`까지 50개 규칙, 표준 파일 전달 수명주기, 준수 체크리스트와 AI용 압축 지침을 포함한다. 버전·승인 상태는 `COR-007`, 공개 채널 발행 전략은 후속 Publishing System 범위로 유지한다.
