## 문서 범위

COR-003은 JCOS를 상속하는 모든 프로젝트의 공통 조사 원칙을 정의한다. 조사 질문과 결정 대상, 포함·제외 범위, 정보 선정 기준, 균형과 대표성, 시간·지역·버전, 불확실성과 공백, 기록·추적성, 종합·인수인계와 중단 조건을 다룬다.

17개 장, `RSH-001`부터 `RSH-050`까지 50개 규칙, 표준 조사 수명주기, 준수 체크리스트와 AI용 압축 지침을 포함한다. 출처 우선순위와 교차 검증은 후속 `COR-004`에서 다룬다.
